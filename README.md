# 📊 Consumer Analytics Project

##  Descripción
Este proyecto tiene como objetivo analizar el comportamiento de compra de clientes, aplicando técnicas de limpieza de datos, métricas de negocio y análisis en SQL.

Se simulan datos de consumo para entender patrones como:
- Penetración de productos
- Frecuencia de compra
- Gasto por cliente

---

##  Objetivo del proyecto
Construir un flujo completo de análisis de datos:
1. Generación de datos
2. Limpieza y transformación (Python)
3. Análisis de métricas (Python y SQL)
4. Preparación para visualización

---

##  Dataset
El dataset contiene:
- customer_id
- product
- units
- price
- sales
- date

Incluye outliers simulados para aplicar técnicas de limpieza.

---

##  Proceso

### 1. Generación de datos
Se generaron 5000 registros simulando comportamiento de clientes.

### 2. Limpieza de datos
- Eliminación de duplicados
- Tratamiento de valores nulos
- Detección de outliers (Z-score / IQR)
- Normalización de variables

### 3. Feature Engineering
- Cálculo de ventas (sales)
- Preparación de datos para análisis

---

##  Métricas calculadas

-  Penetración de producto  
-  Frecuencia de compra  
-  Gasto promedio por cliente  
-  Top clientes  
-  Detección de outliers  

---

##  Análisis en SQL

Se realizaron consultas como:

- Ventas por producto
- Ranking de clientes
- Promedio de gasto
- Distribución de compras
